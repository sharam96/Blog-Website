# Blog Website

A full-stack blog website where users can create, view, and delete blog posts.  
The project uses Node.js, Express.js, PostgreSQL, and Supabase for online database storage.

## Live Demo

https://blog-website-it47.onrender.com

## Features

- Create blog posts
- View all posts
- Delete all posts
- Data stored in online PostgreSQL database
- Fully deployed backend

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- Supabase
- Render
- GitHub

## Database

Posts are stored in a PostgreSQL database hosted on Supabase.

## Deployment

The project is deployed on Render.
